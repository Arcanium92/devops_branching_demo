# CIS 280 — Branching & Pull Request Practice

This is a shared sandbox repo for the Week 3 solo practice exercise.

**You are not going to break anything here.** This repo exists specifically for practicing the fork → branch → commit → push → PR workflow. Experiment freely.

---

## What to do

Follow the instructions in the Week 3 async task on the LMS.

The short version:
1. Fork this repo to your personal GitHub account
2. Clone your fork
3. Create a branch named `feature/your-name-practice`
4. Add your name and track to `CONTRIBUTORS.md`
5. Commit, push, and open a PR back to this repo

---

## What this repo is not

This is not your team project repo. Changes here don't affect your grade beyond the solo practice submission. The only file you should touch is `CONTRIBUTORS.md`.
